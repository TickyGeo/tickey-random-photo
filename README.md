Just click on a "Random Photo" button to get a random photo (if the photo doesn't appear that can be bc of your region)

I used HTML, CSS and JS. I used Lorem Picsum API for getting random images. The function named changePhoto makes src attribute of image tag in HTML to change into an addres which links to a random photo.
